Micrograph codebook lab

Projection matching, the cryo-EM way: build a codebook of rendered views once, then identify a noisy micrograph by nearest-neighbor lookup, with no rendering at query time.
These four structures are stylized stand-ins, not accurate molecular geometry. The demo is about the recognition pipeline, the same pattern real cryo-EM uses to assign particle orientations. It is not about modeling real proteins.
STEP 1 · BUILD CODEBOOK

Novelty-based view dictionary

Each structure is rendered at orientations spread over the whole rotation group SO(3), not just a ring of spins about one axis: view directions from a Fibonacci sphere, each of them rolled in the image plane. A view is stored only if its embedding is far from every view already kept, so symmetric structures compress to a handful while asymmetric ones keep more.
STEP 2 · IDENTIFY

Match a noisy micrograph

One structure is imaged at a hidden orientation drawn uniformly from SO(3), then hit with noise and occlusion. Identity + pose come from the closest codebook entry.
Expect identity to survive this and orientation to survive it only partly. Measured on this codebook: the noise and occlusion move an embedding about as far as a 10–20° rotation does, while a different structure sits four to five times further away. So the lookup names the structure reliably, and pins the pose only to roughly the resolution of the stored views. That is the trade that buys zero renders at query time; a learned embedding is what would sharpen it.

Stain colour
False colour, applied when a buffer is drawn to the screen. Every view in the codebook and every micrograph is rendered in the same neutral grey, so the lookup runs on shape alone and a new stain cannot change a single answer.
