Render to recognize

A vision pipeline with no meshes and no training loop. Objects are drawn as pure distance-field equations, then recognized by rendering candidates and keeping the one that matches. Cryo-EM reads a molecule's orientation from a noisy image the same way. Built in raw WebGL, running live below.

How it works

Everything follows from the first step.

Draw without vertices. A sphere is one short equation instead of a few thousand triangles, so it stays sharp however far you zoom in. Recognize by re-drawing. To identify a hidden object, draw every candidate at every angle and keep whichever drawing matches. Make it fast. Draw those candidates once, store each view as a short list of numbers, and recognition becomes a table lookup — which is how single-particle microscopy reads orientations off a noisy image.

Methods

None of these techniques is new. The work is in building them end to end and making them run in a browser.

The renderer marches signed distance functions by sphere tracing, carves surfaces with fractional Brownian motion, and bores the holed cube with a constructive solid geometry subtract. Edges are supersampled (supersampling, spatial anti-aliasing) and octave count follows a level-of-detail rule as you zoom.

Recognition is render-and-compare: template matching against rendered candidates, which recovers identity and 3D pose together. The codebook turns that search into nearest neighbor search over a de-duplicated dictionary, the same compression idea as vector quantization. The microscopy framing is real: projection matching is how single particle analysis in cryo-EM assigns particle orientations. The method needs a shape it can draw, so it covers rigid objects with a known geometry and not things that differ from one sample to the next — cells on a pathology slide have no fixed template to render against.
